# 品牌输入 | Brand Intake
从现有资料填写；未知项写“待确认”，不要虚构。

| 字段 | 内容 |
|---|---|
| 品牌 / 网站 | 名称、官网、相关页面 |
| 任务 / 模块 | 完整流程或 M1–M6 |
| Business Objective | 业务目标、希望用户采取的行动 |
| Market / Language | 国家、语言、地区、适用时间 |
| Products / Services | 核心产品、规格、价格、可验证优势 |
| Target Audience | 人群、决策阶段、问题、使用场景 |
| Positioning / Voice | 定位、主张、语气、禁用表达 |
| Existing Content | URL、页面类型、更新时间、已知表现 |
| Research Inputs | 查询、关键词、PAA、竞品、访谈、来源链接 |
| Measurement Inputs | GSC/GA4 导出、日期、筛选、事件定义、改版记录 |
| Constraints | 时间、预算、人员、资料、审批要求 |
| Success / Review | 成功指标、复查时间、决策条件 |

最小输入：研究需产品/服务、市场与目标；写作需 Brief 或足够的受众、目标与产品事实；数据诊断需明确指标、时期及实际数据。资料不足时完成不依赖该资料的部分，并明确下一步需要什么。
