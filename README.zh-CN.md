# Search Content Toolkit 中文使用指南

[English guide](README.md)

## 这套 Skill 做什么？
帮助品牌决定：写什么内容、覆盖什么搜索需求、优化哪些页面、怎样写简报与正文，以及如何检查结果。它是**一套 Skill，包含六项能力**，不用记 M1、M2 等编号。

## 六项能力：输入与输出
| 英文名称 | 解决的问题 | 提供什么 | 得到什么 |
|---|---|---|---|
| Find Content Opportunities | 有哪些选题值得做？ | 官网或业务介绍、市场，最好有目标 | 用户需求、选题、内容不足、品牌可增加的价值 |
| Plan Keywords & Pages | 词怎么分组、该对应哪一页？ | 关键词或让它研究候选词、品牌与市场，已有页面如有 | 关键词分组、搜索意图、新建/更新等页面建议 |
| Build a Content Brief | 一篇内容或营销项目应该怎样做？ | 主题、读者、目标、产品事实，已有研究如有 | 单篇内容简报或整体营销项目简报 |
| Write & Review Content | 怎么写、如何检查？ | 简报或足够的需求与事实，语气要求、旧稿如有 | 正文、标题描述、内链建议和质检 |
| Diagnose Search Performance | 表现变化在哪里、为什么、怎么查？ | GSC和/或GA4数据、时期与口径 | 已确认变化、原因假设、排查与优化行动 |
| Prioritise Content Work | 时间和预算有限先做什么？ | 任务清单、业务目标、证据、资源约束 | 先做/后做/暂缓及理由、交付与衡量方式 |

## 最简单的调用
```text
使用 $plan-search-content，分析这个官网：[URL]。
目标市场：[地区]；业务目标：[目标]。
先做内容机会、关键词与页面规划、优先级排序。
根据公开资料开始，区分事实与假设，只告诉我影响判断的关键缺失信息。
请用中文输出。
```

## 每项能力的提示词
### 找选题
```text
使用 $plan-search-content，为[品牌/官网]寻找内容机会。
目标市场是[市场]，目标人群是[人群]，希望实现[目标]。
列出用户需求、选题、已核实的内容不足、品牌可以增加的价值和证据来源。
```
### 关键词与页面规划
```text
使用 $plan-search-content，整理附件关键词。
品牌：[品牌]；市场：[市场]；现有页面：[链接或附件]。
按用户需求分组，判断搜索意图，建议哪些需求放在同一页、哪些页面新建或更新。不要编造搜索量。
```
### 写简报
```text
使用 $plan-search-content，为[主题]制作Content Brief。
读者：[人群]；目标：[行动]；主关键词：[如有]；已核实产品资料：[材料]。
包含内容角度、大纲、证据、内链、CTA和衡量方式，单独列出待补资料。
```
### 写作与检查
```text
使用 $plan-search-content，根据附件简报和产品事实撰写或修改[页面/文章]。
语言与风格：[要求]；篇幅：[可选]。
交付正文、标题描述、内链建议和事实检查，编辑问题不要混入正文。
```
### 数据排查
```text
使用 $plan-search-content，排查[问题]。
附件：[GSC和/或GA4导出]；本期：[日期]；对比期：[日期]；市场与筛选：[口径]。
关键事件定义与已知改动：[说明]。
先验证数据，再找主要变化，区分事实与假设，输出排查、行动及复查方式。
```
### 排优先级
```text
使用 $plan-search-content，为这些任务排序：[清单]。
业务目标：[目标]；已有证据：[资料]；可用时间与预算：[约束]。
分为先做、后做、暂缓，解释价值、成本、依赖、最小交付和衡量方式。
```

## 只有官网能不能开始？
可以先审阅公开内容、提出候选选题、做初步页面规划。不能仅凭官网判断真实流量、转化或ROI。
关键词列表能让分组更具体；GSC支持搜索展示和点击分析；GA4支持站内访问与行为分析。两者不必同时提供，但分析具体问题需要对应数据；比较变化通常需要可比时期。
PMax与Search广告导出可提供搜索需求线索，但这套内容工具并不包含完整的广告预算、出价和投放效率审计，那需要独立广告分析流程。

## 要全部跑一遍怎么说？
```text
使用 $plan-search-content，为[品牌/官网]做完整内容方案。
市场：[地区]；目标：[目标]；读者：[人群]；资料：[链接或附件]；资源：[约束]。
完成选题、关键词与页面规划、优先级排序，并为最优先主题制作一份简报和正文。
有实际分析数据时先排查数据；没有时给衡量计划及具体数据需求。
```

## 英文与中文
英文说明方便公开展示，也支持英文、中文和双语输入输出。浏览器翻译可辅助阅读GitHub页面；本中文指南提供明确对照，不依赖自动翻译。阅读GitHub链接不等于安装Skill；在已经提供该Skill的助手里调用即可。
